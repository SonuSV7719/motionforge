# Example 02 — SaaS Metric Showreel

Sleek, high-conversion SaaS feature showcase video with glassmorphic cards, floating metric chips, and smooth entrance easing.

## Video Output
- **File**: `output/saas-showreel.mp4`
- **Resolution**: 1920x1080 (16:9 Landscape)
- **Framerate**: 60 FPS
- **Duration**: 6.0 seconds

## Render with MotionForge CLI
```bash
# Render video directly to MP4
mf render -o output/saas-showreel.mp4
```
