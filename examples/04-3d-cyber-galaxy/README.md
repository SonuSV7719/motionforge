# Example 04 — 3D Cyber Galaxy & Geometric Hologram

True 3D Three.js WebGL motion graphics with floating metallic geometry, particle galaxy swirls, and kinetic typography.

## Video Output
- **File**: `output/3d-cyber-galaxy.mp4`
- **Resolution**: 1920x1080 (16:9 Landscape)
- **Framerate**: 60 FPS
- **Duration**: 6.0 seconds

## 3D Features
- Real-time Three.js WebGL rendering layer
- Metallic Torus Knot PBR material with directional lighting and specular highlights
- Deterministic frame-by-frame 3D rotation synchronized with GSAP seek hooks
- Floating glassmorphic category pill and glow drop-shadow title

## Render with MotionForge CLI
```bash
# Render video directly to MP4
mf render -o output/3d-cyber-galaxy.mp4
```
