# Example 01 — Cyberpunk Kinetic Intro

Electrifying 1080p 60fps futuristic motion graphics video with layered neon elements, kinetic typography, and GSAP spring animations.

## Video Output
- **File**: `output/cyberpunk-intro.mp4`
- **Resolution**: 1920x1080 (16:9 Landscape)
- **Framerate**: 60 FPS
- **Duration**: 6.0 seconds

## Render with MotionForge CLI
```bash
# Render video directly to MP4
mf render -o output/cyberpunk-intro.mp4

# Or with custom quality / preset
mf render -o output/cyberpunk-intro.mp4 --preset youtube-1080p
```
