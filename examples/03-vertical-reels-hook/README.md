# Example 03 — Vertical Social Reels Hook

Attention-grabbing 1080x1920 9:16 vertical video formatted for Instagram Reels, TikTok, and YouTube Shorts.

## Video Output
- **File**: `output/viral-reels-hook.mp4`
- **Resolution**: 1080x1920 (9:16 Vertical)
- **Framerate**: 60 FPS
- **Duration**: 5.0 seconds

## Render with MotionForge CLI
```bash
# Render video directly to MP4
mf render -o output/viral-reels-hook.mp4
```
