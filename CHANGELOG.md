# Changelog

All notable changes to MotionForge will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Core scene model (Scene, Track, Clip, Keyframe, Timeline)
- HTML/CSS/GSAP compositor engine
- Headless Chrome frame capture renderer
- FFmpeg encoding pipeline
- CLI with commands: `init`, `scene`, `track`, `clip`, `text`, `template`, `effect`, `render`, `preview`
- Template engine with registry, validator, and customizer
- Effects library: transitions, filters, animations, easing, text effects
- Asset manager with Google Fonts integration and media probe
- 14 built-in templates across 8 categories
- 11 output presets for all major platforms
- 7 agent skills for AI coding agent integration
- Optional MCP server wrapper
- 7 example projects with walkthroughs
- Full documentation suite
